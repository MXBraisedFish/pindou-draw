开发环境需要 Node.js 20.19+ 或 22.12+。首次运行执行 `npm ci`，使用 `npm run dev` 启动开发服务器，`npm run build` 会进行 TypeScript 检查并生成 `dist/`。单元测试使用 `npx vitest run`；浏览器测试先执行 `npx playwright install`，再运行 `npm run test:e2e`。

工程导入支持新版 `.pindou.json` 和旧版 `.pd`。新版仍导出 v4 格式；旧工程的色号网格、色卡和六种颜色类型会在导入时自动转换，保存后即为新版工程。转换以仓库最后保留旧代码的 `815b2ba` 为依据（随后 `a0d6b79` 删除旧代码）；旧导出器最后一次修改在 `419f88e`，其 v2 格式与重构前 `b90d6f2` 相同。测试样本由该旧导出器实际生成。

旧工程超过 64 格时，电脑和平板会将完整像素拆分为每块 64 × 64 的画布组，边缘不足一块的部分补空格。画布组最大 16 × 16，可容纳旧版最大 1024 × 1024 格的工程。手机仅支持宽、高均不超过 64 格的单画布，较大的旧工程请使用电脑或平板导入。

色板的“历史颜色”保存最近选择的五个色号，重复选择会移动到最前面。它只在本次页面会话中保留；切换色卡、导入工程或刷新页面后清空，不会从工程文件或浏览器存储中恢复。
